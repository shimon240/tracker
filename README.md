# ApplyTrack — Трекер откликов на вакансии

Веб-приложение для отслеживания откликов на вакансии с быстрым обновлением статусов, заметками и полными описаниями позиций.

## Стек технологий

- **React 19** + **TypeScript**
- **Vite 8** — сборка
- **Tailwind CSS v4** — стили
- **Radix UI** — доступные примитивы компонентов
- **date-fns** — форматирование дат
- **lucide-react** — иконки
- **localStorage** — персистентность данных

## Возможности

- Добавление и редактирование откликов с полной информацией
- Статусы: Отправлено → HR / Скрининг → Тех. интервью → Финальное → Оффер → Принято
- Быстрое изменение статуса прямо из карточки
- Поиск по компании, должности, заметкам
- Фильтрация по статусу и способу отклика
- Сортировка по дате, компании, должности, статусу
- Архивирование закрытых откликов
- Статистические карточки на дашборде
- Полное описание вакансии в модальном окне
- Данные сохраняются в localStorage

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Сборка для продакшена

```bash
npm run build
npm run preview
```
